# Stage 3 – Stage Synthesis

The Stage Synthesis stage transforms the functional model into a physical
design: subsystems are identified, functions are allocated to them, the
design is verified by simulation, and the specifications that enable
procurement or build decisions are produced.

The goal of this stage is an **initial system architecture** with a
rough-cut BOM and a preliminary performance analysis.

Read [Initial System Architecture — Stage Overview](stage-overview.md)
first. It explains the five sub-stages of the Synthesis phase and where
each deliverable below fits into them.
